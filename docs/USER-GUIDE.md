# Polis 社区平台 - 用户使用指南

> 最后更新: 2026-04-30 | 版本: v0.2.5

---

## 一、快速开始

### 1.1 访问平台
打开浏览器访问: **https://www.mzgw.com**

### 1.2 注册账号
1. 点击右上角「注册」按钮
2. 填写用户名、显示名称、邮箱、密码
3. 点击注册，自动登录

### 1.3 登录
- 点击右上角「登录」
- 输入邮箱和密码
- 支持跨设备登录（token 存储在浏览器本地）

---

## 二、浏览与发现

### 2.1 首页
登录后首页展示：
- **推荐社区** - 热门社区列表
- **最新帖子** - 全站最新内容流
- **侧边栏** - 快捷导航和创建社区入口

### 2.2 发现社区 (`/explore`)
- 浏览所有公开社区
- 支持搜索过滤（标题/命名空间/描述）
- 社区卡片显示成员数和帖子数

### 2.3 热门社区 (`/trending`)
- 按帖子数排序展示热门社区
- Top 3 社区带金银铜排名徽章
- 点击卡片进入社区主页

### 2.4 热榜 (`/hot`)
- 按成员数排名的榜单视图
- 列表形式展示，一目了然

### 2.5 搜索 (`/search`)
- 顶部搜索框可搜索社区、帖子、用户
- 搜索结果按类型分组展示

---

## 三、社区

### 3.1 创建社区
1. 点击「创建社区」按钮
2. 填写社区信息：
   - **命名空间 (slug)**: 英文标识符，如 `my-community`
   - **标题**: 社区显示名称
   - **描述**: 社区简介
   - **可见性**: 公开/私有/不公开
3. 提交创建

> 创建后会自动生成一个根社区（namespace 为 slug）和一个你的个人子社区（namespace 为 `你的用户名/slug`）。

### 3.2 社区主页 (`/space/{namespace}`)
- **基本信息**: 标题、描述、成员数、帖子数
- **公告**: 紧急公告（红色）和重要公告（黄色）在顶部横幅展示
- **加入社区**: 点击「加入社区」按钮成为成员
- **功能标签页**:
  - **帖子** - 社区帖子列表，Markdown 语法
  - **成员** - 社区成员列表
  - **投票** - 社区内的投票和问卷

### 3.3 嵌套社区
支持多级社区结构，如：`/space/username/community-name`
系统自动处理多段命名空间路径。

---

## 四、内容创作

### 4.1 发布帖子
在社区页点击「写文章」→「发布」，或在 `/post/new?space={namespace}` 直接进入编辑器：
- **标题**: 必填
- **正文**: 支持 Markdown 语法
- **标签**: 可添加多个标签
- **模块类型**: 论坛（默认）/ 文章

### 4.2 Markdown 语法支持
```markdown
# 一级标题
## 二级标题
### 三级标题

**粗体** *斜体* ~~删除线~~

- 无序列表
1. 有序列表

[链接文字](https://example.com)
![图片](https://example.com/image.png)

> 引用文字

`行内代码`

​```
代码块
​```
```

### 4.3 评论
- 在帖子页面底部发表评论
- 支持对评论点赞

### 4.4 帖子交互
| 操作 | 说明 |
|------|------|
| 👍 点赞 | 点击点赞按钮，再次点击取消 |
| ⭐ 收藏 | 收藏帖子到「我的收藏」 |
| 🚩 举报 | 举报违规内容 |

## 五、社交功能

### 5.1 关注/粉丝 (`/profile/{username}`)
- 访问他人主页，点击「关注」按钮
- 再次点击「已关注」可取消关注
- 主页显示**粉丝数**和**关注数**
- 点击数字可展开粉丝/关注列表

### 5.2 个人主页 (`/profile`)
- **帖子** - 你发布的帖子
- **社区** - 你参与的社区
- **粉丝** - 关注你的人
- **关注** - 你关注的人

### 5.3 编辑个人资料
在个人主页可修改：
- 显示名称
- 个人简介 (Bio)

## 六、投票系统

### 6.1 发起投票
1. 进入 `/polls/new`
2. 填写投票标题和说明
3. 选择类型：**单选** / **多选**
4. 添加选项（至少 2 个）
5. 创建投票

### 6.2 参与投票
- 投票嵌入在社区帖子流中
- 选择选项后点击投票
- 可查看实时投票结果

### 6.3 投票中心 (`/polls`)
- 投票功能导航页
- 引导用户进入社区浏览和发起投票

## 七、更多功能

- 查看平台各版本更新内容
- 当前版本标记显示

## 八、管理后台

## 九、常见问题

### Q: 忘记密码怎么办？
访问 `/forgot-password` 通过邮箱重置密码。

### Q: 如何创建嵌套社区？
在创建社区时，系统自动根据你的用户名创建 `用户名/社区slug` 格式的子社区。

### Q: 可以删除帖子吗？
可以。管理员在后台可以删除帖子，普通用户在帖子页面也可删除自己的帖子。

### Q: 数据可以导出吗？
访问 `/export` 页面，支持 Markdown 和 JSON 格式导出。

### Q: 发现 Bug 怎么反馈？
在社区中发帖描述问题，或在 Polis HQ 社区反馈。
